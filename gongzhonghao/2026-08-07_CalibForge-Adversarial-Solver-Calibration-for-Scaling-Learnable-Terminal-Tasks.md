## 智源团队发布CalibForge：自博弈校准生成5431个终端任务，最强Agent性能暴涨24.7个百分点！

大模型Agent在终端环境中的任务求解能力，正成为衡量其真实工程水平的关键标尺。然而，高质量训练数据的匮乏始终是制约Agent能力突破的瓶颈——**“可执行”的任务并不等于“适合学习”的任务**。一篇来自智源研究院等机构的最新论文，提出了一种名为 **CalibForge** 的自主任务合成系统，通过“对抗性求解器校准”机制，让大模型在互相博弈中自动生成高难度、可学习的终端任务，在多个权威榜单上刷新了性能纪录。

### 一、核心方法：把任务构建变成一场“猫鼠游戏”

CalibForge的核心创新在于，将任务构建从单向的数据生成，转变为 **“作者-求解器”对抗循环**。论文提出，一个理想的训练任务，应当处于“求解器相对可学习区”内：既要让模型能够解出，又不能让它轻易解出。为此，CalibForge设计了两种校准策略：

1.  **多求解器校准**：让多个不同能力的求解器（如DeepSeek-V4-Flash、GLM-5、Kimi K2.5）尝试同一任务，并设置保留标准为**至少一个成功、一个失败**，以此捕捉跨模型的能力差异。

2.  **对比求解器校准**：指定强、弱两个求解器（如DeepSeek-V4-Pro和Flash），要求必须呈现 **“强通过、弱失败”** 的特定结果模式，从而将任务难度锁定在两个模型的能力区间内。

论文用数学公式清晰定义了这一“可学习区”的判定标准：

![图1：CalibForge架构总览，两种校准策略示意图](https://arxiv.org/html/2608.06352v1/x3.png)

多求解器校准的核心公式，要求成功数严格介于0和总求解器数K之间：

$$C_{\mathrm{multi}}(\mathbf{y})=\mathbf{1}\!\left[\,0<\sum_{i=1}^{K}y_{i}<K\,\right]$$

对比校准则更为严苛，必须同时满足强求解器成功、弱求解器失败：

$$C_{\mathrm{con}}(y_{\mathrm{s}},y_{\mathrm{w}})=\mathbf{1}\!\left[\,y_{\mathrm{s}}=1\land y_{\mathrm{w}}=0\,\right]$$

这一过程的精妙之处在于“动态修正”。当任务不符合保留标准时，作者智能体会根据求解器的失败轨迹进行针对性修订，然后重新验证和探测，直到符合要求。整个流程如图2所示，**求解器的行为反馈直接参与任务的迭代优化**，而非简单的事后过滤。

![图2：CalibForge完整的任务生成与校准流水线](https://arxiv.org/html/2608.06352v1/x4.png)

实验数据显示这一策略的威力：所有通过初筛的任务中，**仅有19%** 首次探测就符合“强通过/弱失败”标准，但经过平均多轮修订后，**累计保留率高达96%**。这充分说明，“不可解”往往不是任务本身的缺陷，而是难度定位的偏差。

### 二、实验效果：数据质量决定Agent能力上限

基于5,431个校准任务，论文使用DeepSeek-V4-Pro进行轨迹蒸馏，并微调了Qwen系列模型。在权威的Terminal-Bench 2.0基准上，CalibForge展现出碾压级优势：

| 训练数据 | Terminal-Bench 2.0 准确率 (%) |
| :--- | :--- |
| **CalibForge (35B)** | **47.57 ± 0.99** |
| TerminalTraj (35B) | 40.82 ± 0.75 |
| TermiGen (35B) | 40.07 ± 0.99 |
| **CalibForge (30B)** | **32.58 ± 1.12** |
| TermiGen (30B) | 23.60 ± 1.12 |
| 基础模型 (30B) | 7.87 ± 0.00 |

在30B参数模型上，CalibForge将Terminal-Bench 2.0分数从7.87%提升到32.58%，**相对基础模型提升了24.71个百分点**；在35B模型上，相比最强基线TerminalTraj也高出了6.75个百分点。论文的消融实验（表3）进一步证明，多求解器校准和对比校准的增益分别比无反馈（22.47%）高出6.74和8.62个百分点，远超单求解器反馈（24.34%）。

这些能力并非“记忆性”的。在分布外测试中，CalibForge训练的模型在SWE-bench Pro上相对基础模型提升27.68个百分点，在Doc2Repo上提升30.04个百分点。图3的类别细分也显示，提升并非集中在单一领域，而是在软件工程、系统管理、科学计算等全部类别上均有改善或保持。

### 三、展望：从“任务工厂”到Agent的自我进化

CalibForge的价值不仅在于提供了一个高质量数据集，更在于它展示了一种全新的数据生产范式：**让智能体在对抗中发现自身的知识盲区，并生成针对性的“训练题”**。这种基于求解器行为的校准机制，有望成为未来合成数据领域的标准组件。当任务不再是静态的，而是随着模型能力增长动态演化时，Agent的训练或许将真正进入自我博弈的快车道。如何进一步降低多轮校准的计算成本，并探索更复杂的多智能体对抗博弈，将是后续值得关注的方向。
