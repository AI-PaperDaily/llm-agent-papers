## **HeyGen发布Avatar V：视频参考Avatar生成突破1080p无限时长，Sparse Reference Attention核心驱动性能碾压SOTA**

### **一、引言**

生成一个数字人，使其不仅外貌与真人几乎无差，连讲话的节奏、习惯性的小动作都具备高相似度，这曾是视频生成领域的“圣杯”。现有方法大多依赖单张静态参考图，但这显然不够——一张图无法捕捉一个人的动态行为模式，导致生成的数字人普遍存在“身份漂移”和“机械感”的问题。为解决这一挑战，HeyGen研究团队推出了名为 **Avatar V** 的生产级框架。该方案通过直接将参考视频的完整Token序列作为身份条件，利用**Sparse Reference Attention**机制线性地处理任意长度的参考视频，并能在单一系统中实现1080p、无限时长的数字人视频生成。在“跨场景”基准测试中，Avatar V在身份保持、唇音同步和生成质量上全面超越Seedance 2.0、Kling O3 Pro等业界竞品。

### **二、核心方法**

![图1：Avatar V架构图：多模态输入被 Patchify 为统一Token序列，通过Sparse Reference Attention和运动注入模块等处理](https://arxiv.org/html/2606.13872v1/x1.png)

Avatar V的核心架构基于 Diffusion Transformer（DiT），其最大创新在于将身份建模重新定义为一个**视频参考条件**问题。整套系统包含三大核心支柱：视频参考身份建模（Sparse Reference Attention）、**运动建模（Motion Representation）**，以及**身份感知超分辨率细化器**。

#### **1. 视频参考身份建模与 Sparse Reference Attention**

过去，系统要么将身份压缩成固定长度的嵌入向量（造成信息丢失），要么简单地将所有参考Token与生成Token拼接（导致二次方计算复杂度）。Avatar V提出了不对称的 **Sparse Reference Attention** 机制来化解这一矛盾。

具体来说，生成Token会“关注”所有参考Token，以提取全局的静态与动态特征；而参考Token则仅进行自注意力计算，无需关注回生成Token。通过引入结构化稀疏掩码，该机制将计算复杂度从二次方降低为线性。引入该机制后，系统处理数分钟长的参考视频变得可行，从而可以捕获人物的说话节奏、习惯性微表情和手势倾向。

核心优势在于：
$$O(T_{ref}^2 + T_{gen}^2) \rightarrow O(T_{ref} + T_{gen}^2)$$
这一公式揭示了系统如何在不牺牲性能的前提下，将计算量从二次方缩减至线性增长。

#### **2. 运动表示流：闭环式风格建模**

除了外貌，一个令人信服的数字人必须“动起来也像那个人”。传统方法往往将运动信号视为分离的条件，无法捕捉人物的个体化动作风格。Avatar V为此设计了一个专用的**运动表示流**。该流在整个生成过程中扮演“双重角色”：

- **作为生成目标**：模型学习生成匹配该人物风格的运动序列。
- **作为条件信号**：在训练时，该运动流又回传给模型，形成一个闭环的优化信号。

这种联合优化设计使模型能够统一理解目标讲话者的运动动力学，即使面对全新的语音内容，也能生成具有**行为一致性**的视频。

![图2：Avatar V训练流程：五阶段渐进式训练，从文本到视频预训练到人类反馈对齐](https://arxiv.org/html/2606.13872v1/x2.png)

#### **3. 身份感知超分辨率细化器**

基础DiT模型通常在较低分辨率下运行以控制计算成本。为了获得高清输出，Avatar V配备了一个**身份感知超分辨率（SR）**细化器。该细化器并非一个独立于身份的小模型，而是完整继承了视频参考条件装置。它利用参考视频的身份特征和音频信号，在放大分辨率的同时精准恢复面部细节（如牙齿结构、皮肤纹理和微表情）。

为了兼顾推理效率，细化器采用了**稀疏时间注意力**，将每帧的视野限制在局部时间窗口内。结合蒸馏技术，该SR模块仅需单步去噪即可完成从低分到1080p的细节还原，在保证画质的同时创造了极低的推理延迟。

### **三、实验与性能**

为验证Avatar V的鲁棒性，研究者构建了一个极具挑战性的**跨场景**基准（70个测试案例），要求模型在给定参考视频后，基于“目标人物在同一场景”“跨场景”以及“AI生成的场景”三种不同模式下完成视频生成。评估维度包括自动客观指标和人类主观评价。

**客观指标对比：**

| 方法 | Sync-C ↑ | Face Sim ↑ | Q-Align ↑ |
| :--- | :--- | :--- | :--- |
| Kling O3 Pro | 5.16 | 0.838 | 4.80 |
| Veo 3.1 | 8.05 | 0.714 | 4.95 |
| OmniHuman 1.5 | 7.53 | 0.732 | 4.70 |
| Seedance 2.0 | 8.86 | 0.823 | 4.85 |
| **Avatar V（Ours）** | **8.97** | **0.840** | **4.85** |

表中可以看到，Avatar V在音唇同步（Sync-C）和身份保持（Face Sim）上取得了最高分，尤其Face Sim（0.840）非常接近真实视频的上限（0.861）。

**主观评价：**

![图10：MOS雷达图：Avatar V在身份一致性、唇音同步、运动自然性等6个维度均获得最高分](https://arxiv.org/html/2606.13872v1/x7.png)

在人类评分的主观评价（Mean Opinion Score，MOS）中，Avatar V在“身份一致性”、“运动自然性”和“伪影控制”等所有六个维度上均以显著优势领先。特别是在“身份一致性”上获得了接近满分的4.98分。

在成对盲测（Pairwise Win Rate）中，Avatar V相对于OmniHuman 1.5的胜率高达85.7%，相对于Seedance 2.0的胜率为68.9%，表明在复杂跨场景任务下，该方案的用户偏好压倒性胜出。

此外，在“图灵测试”中，有61.1%的测试案例里，至少有一位人类评审员将Avatar V生成的视频误认为是真人录制，证明了其极高的视觉逼真度。

### **四、展望**

Avatar V通过将身份建模从单张图像升级为完整的视频参考条件，以及Sparse Reference Attention等工程创新，显著拉近了数字人与真人之间的界限。这套系统不仅可作为个人虚拟分身、影视制作工具，在直播、远程会议和游戏交互等追求“视觉真实感”的领域也具有极强的应用潜力。

随着数据引擎和RLHF对齐（Reinforcement Learning from Human Feedback）进一步优化，未来通用视频生成模型的标准，很可能从“理解画面”全面转向“理解人物性格与行为”。到那时，我们该如何定义屏幕中的“身份”？或许，答案已经体现在Avatar V的每一个Token之中。
