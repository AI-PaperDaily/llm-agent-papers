# UIUC与CMU稳住Agent异步训练：BabyAI得分达最强基线9.9倍！

## 一、引言

训练能够调用工具、操作环境的Agent，往往需要同时生成轨迹和更新模型。异步强化学习可以提高训练吞吐量，却也带来一个问题：轨迹生成完成时，学习器可能已经更新过多次，产生数据的策略与当前策略不再一致。

即使模型权重没有变化，训练与推理使用不同精度或计算内核，也可能让两者对同一动作给出不同概率。面对这种**离策略数据**，简单复用旧轨迹可能使更新方向偏离当前模型真正需要的方向；重要性采样虽然能校正一部分差异，又可能带来极端梯度。

UIUC与CMU等机构的研究者提出**Regularized Score Centering（RSC，正则化分数中心化）**：在消除奖励基线干扰的同时，限制学习器偏离数据生成策略的程度。理解这一方法，有助于区分异步Agent训练中的两类问题：单次更新是否稳定，以及旧轨迹是否仍能代表当前策略。

## 二、核心方法

### 重要性采样：修正动作分布，但可能放大梯度

设当前学习器为 $\pi_\theta$，生成训练数据的行为策略为 $\mu$。在同一历史 $h$ 下，动作 $a$ 的重要性比率是 $\rho(h,a)=\pi_\theta(a\mid h)/\mu(a\mid h)$；它衡量该动作在两个策略下的相对概率。

完整的序列级重要性采样需要连乘整条回复的 token 比率，长序列容易出现高方差。**截断重要性采样（TIS）**改为限制 token 权重，减轻极端梯度，但截断也会引入偏差。

更重要的是，token 级校正只针对给定历史下的下一动作：它既不校正此前历史的分布，也不修正动作之后由旧策略生成的后续轨迹。

### Score Centering：消除奖励基线造成的更新漂移

**Score Centering（SC，分数中心化）**处理的是另一类偏差。策略的“分数”是对数概率的梯度，记为 $\psi_\theta$。在学习器自己的动作分布下，分数的均值为零；但在行为策略下，这个均值不一定为零。

因此，本来不应区分动作的共同奖励基线，也可能推动参数更新。SC 在同一历史下减去行为策略的平均分数：

$$
\mathbb{E}_{\mu}\!\left[R\bigl(\psi_{\theta}-\mathbb{E}_{\mu}[\psi_{\theta}]\bigr)\right]
=\mathbb{E}_{\mu}[A_t^\mu\psi_{\theta}]。
$$

这表示精确中心化后，期望更新只保留行为策略下的动作优势 $A_t^\mu$ 所对应的部分，消除了共同基线的贡献。

SC 也能与 TIS 组合：此时被减去的是**加权分数的条件均值**，辅助动作与实际动作使用相同的截断规则。实践中，条件均值通过在同一历史下从行为策略独立采样辅助 token 来估计，不需要额外运行环境或计算奖励。

但中心化不能解决所有离策略问题。动作优势仍取决于行为策略如何继续完成轨迹；学习器变化较大时，旧策略认为无价值的动作，可能恰好能被新策略用于后续决策。

### Regularized Score Centering：用反向KL限制策略偏移

RSC 在 SC 或 SC+TIS 上加入**反向 KL 正则化**，比较同一历史下学习器与行为策略的下一 token 分布。它不是让两个策略永远相同，而是在使用旧数据拟合期间，对过大的偏移施加代价。

![图1：RSC在分数中心化基础上约束学习器与行为策略的分布差异](https://arxiv.org/html/2611.21791v1/kl_role_agentic.png)

固定行为策略和 token 优势后，RSC 的代理目标可写为：

$$
\mathcal{W}(\pi_{\theta})=
\mathbb{E}_{Y\sim\mu}\!\left[
\sum_{t=1}^{H}
\left(
A_t^\mu F_a(\rho_t)
-\beta(\rho_t\log\rho_t-\rho_t+1)
\right)
\right]。
$$

其中第一项依据旧策略下的优势奖励动作，第二项在行为策略下取条件期望后对应反向 KL 惩罚，$\beta$ 控制限制强度。

这里 $F_a$ 由所选权重函数决定；不使用重要性采样时，它退化为 $\log\rho$。实际训练不能直接得到每个 token 的期望优势，而是使用组内中心化的响应奖励，并结合辅助 token 估计中心项：

$$
\widehat{g}_{i,t}^{\rm RSC}
=A_i\!\left(
\rho_{i,t}^{\rm TIS}\psi_{i,t}
-\widehat{\mathbb{E}}_{\mu}[\rho^{\rm TIS}\psi_\theta\mid h_{i,t}]
\right)
-\beta\widehat{\mathbb{E}}_{\mu}
[\rho^{\rm KL}\log\rho^{\rm KL}\psi_\theta\mid h_{i,t}]。
$$

这一更新由**中心化奖励梯度**和**KL 惩罚梯度**组成：前者减少基线干扰，后者限制策略偏移；KL 权重也可以单独截断，此时对应的是修改后的正则目标。

行为策略刷新后，KL 参照也随之更新；完全异步训练中，不同样本则对应各自产生时的行为策略。理论分析在有限确定性 token 树、二元终止奖励等条件下表明，充分拟合正则化目标可以转化为奖励进展；该保证依赖指定的拟合和采样条件，不能直接视为任意实际训练都单调提升。

## 三、实验

首先，中心估计本身会影响训练。与原 SC 使用的 Top-128 概率及尾部近似相比，在 Countdown 和数学任务中，测试过的蒙特卡洛中心估计都取得了更高的最终评估分数。数学对比每种设置使用一个随机种子，Countdown 使用三个随机种子。

![图2：蒙特卡洛中心估计与Top-128近似的训练和评估对比](https://arxiv.org/html/2611.21791v1/countdown_failure_estimators.svg)

更准确的中心估计仍不足以消除策略陈旧问题。在相同采样器刷新间隔下，稠密模型的数学任务中，加入 KL 对最终平均准确率的改变小于一个百分点；而在交互环境 Crafter 中，RSC（TIS）明显优于 SC+TIS。这组对比同时涉及不同任务和模型，因此不能把差异完全归因于任务结构。

延长刷新间隔后，学习器可以在旧策略固定期间更新更多次。Countdown 的最大测试间隔下，即使使用蒙特卡洛中心，RSC（TIS）的最终留出奖励仍比 SC 高约 **65 个百分点**；MoE 数学实验中，SC 在最长间隔下也落后于 SC+TIS。

![图3：采样器刷新间隔增加时的Countdown和MoE数学任务表现](https://arxiv.org/html/2611.21791v1/staleness_comparison.png)

在六项受控异步 Agent 任务中，RSC（TIS）整体处于领先水平。下表为三个随机种子的最终评估均值；Crafter 使用几何成就分数，Craftax 使用总回合奖励，其余列出的任务以百分比报告。

| 任务 | 对比基线 | 基线得分 | RSC（TIS） |
|---|---|---:|---:|
| WebShop | IS-PPOClip | 74.81% | 74.80% |
| AppWorld dev | SC+TIS | 12.28% | 14.04% |
| BabyAI | IS-PPOClip | 1.83% | 18.06% |
| Crafter | IS-PPOClip | 9.34 | 14.21 |
| Craftax | IS-PPOClip | 4.04 | 4.71 |

其中，AppWorld 相对 SC+TIS 提升 **14.3%**；BabyAI 得分约为最强非 RSC 基线 IS-PPOClip 的 **9.9 倍**。WebShop 上两者基本持平，IS-PPOClip 的均值略高。训练曲线还显示，在 Crafter 和 Craftax 中，相同采样响应数量下，RSC（TIS）获得了更高训练奖励。

![图4：六项交互任务的训练奖励曲线](https://arxiv.org/html/2611.21791v1/agentic_training.png)

最后，在完全异步的软件工程训练中，轨迹完成时间和队列等待共同形成策略延迟。SWE-bench Verified 的 Average@8 评估显示：学习率为 $10^{-6}$ 时，不使用 IS 的 RSC 得分为 **61.14%**，高于 SC 的 **58.48%**；学习率为 $2\times10^{-6}$ 时，RSC（TIS）为 **54.47%**，高于 SC+TIS 的 **36.04%**。这两组配置每种方法各使用一个随机种子，且只评估了部分基线。

![图5：完全异步软件工程训练的奖励与策略概率差异](https://arxiv.org/html/2611.21791v1/swe_preliminary.svg)
