# 阿里发布Qwen-UI-Agent：混合GUI+CLI架构登顶手机Agent榜单，92.2%成功率惊艳业界

GUI Agent正站在从实验室走向真实世界的拐点上。模拟器里跑得飞快的模型，一上真机就频频翻车：弹出广告、验证码、失灵的滑动条，让无数号称“SOTA”的模型原形毕露。面对这一困境，阿里近日发布的Qwen-UI-Agent给出了自己的答案——高达92.2%的真实设备任务成功率，在MobileWorld-Real基准上以碾压姿态超越所有闭源模型。真机、大模型、混合行动空间、在线强化学习，这波组合拳能否真正打通GUI Agent的“最后一公里”？

## 一、核心方法

### 1. 真实设备移动运行时：补齐模拟到真实的鸿沟

论文指出，现有多数移动Agent在模拟环境中表现优异，但面对真实设备时，应用状态动态变化、权限请求、验证码、网络波动等高频干扰让模型频繁翻车。为此，团队构建了包含**超过100台物理设备和150余个应用的实时移动运行时**。

该框架引入健康感知调度器，持续追踪每台设备、应用、账户、网络连接和显示器的健康状态，实现动态任务路由。更巧妙的是，采用虚拟屏幕机制让一台物理手机同时承载多个应用会话，将真实设备集群的Rollout吞吐量提升了约20倍。

### 2. 混合GUI+CLI行动空间：用两条腿走路

单一GUI操作在结构化任务面前显得冗长低效。Qwen-UI-Agent将行动空间统一为GUI操作、CLI命令、API调用和用户交互的集合，支持在单次模型决策中批量输出多个动作：

$$(r_t, \mathbf{a}_t) = \pi_\theta(I, o_t, h_t)$$

其中 $o_t = (o_t^{GUI}, o_t^{CLI}, o_t^{API})$ 表示多通道观察，既包含屏幕截图，也包含命令执行结果和结构化API反馈。当 $K_t > 1$ 时，模型可在一个决策步内输出有序动作序列：

$$\mathbf{a}_t = (a_t^{(1)}, \ldots, a_t^{(K_t)}), \qquad a_t^{(k)} \in \mathcal{A}_t$$

在OSWorld-v2上，CLI动作占比达55.1%，超过40%的动作以批量形式输出，大幅压缩了执行轨迹长度。

### 3. Agent驱动数据飞轮：让系统自己变强

传统的“人工构造数据-训练-评估-分析失败”流程在跨应用、跨平台扩展时严重拖慢迭代。Qwen-UI-Agent提出了AutoResearch风格的自动化数据飞轮，由Agent自动完成**任务合成、环境构建、验证器生成、失败分析**，人类仅负责全局监督和关键干预。

训练过程采用分阶段的强化学习框架：先通过SFT获得初始策略，再用Action RL纠正六类常见局部错误，最后用在线RL优化端到端的长程决策。在线RL采用GRPO算法，基于验证器计算的轨迹级优势进行更新：

$$\hat{A}_i = \frac{r_i - \bar{r}_x}{\operatorname{Std}(r_1, \dots, r_K) + \epsilon}$$

其中验证器评估最终环境状态 $s_{\text{final}}^{(i)}$ 并输出二进制奖励 $r_i$。配合模型自适应任务课程，系统持续将中等成功率任务推入活跃训练池，将已掌握任务移入监控池，动态捕捉模型的学习边界。

![图2：Qwen-UI-Agent真实设备运行时与调度机制](https://arxiv.org/html/2607.28227v1/x4.png)

### 4. 前摄服务与跨平台执行

Qwen-UI-Agent不止被动执行任务，还能主动识别手机通知中的行动信号。以航班取消为例：系统解析通知为结构化事件，关联用户的行程与日程，搜索替代方案，最终生成决策就绪的改签方案等待用户确认。跨平台执行能力则通过层次化规划器-执行器架构实现，支持移动端与桌面端的设备寻址动作和共享执行状态。

## 二、实验结果

![图3：Qwen-UI-Agent各项基准性能概览](https://arxiv.org/html/2607.28227v1/x1.png)

**移动端表现**：Qwen-UI-Agent-27B在MobileWorld上取得82.1%的成功率，超越GPT-5.6 Sol（70.1%）12个百分点；在真实设备基准MobileWorld-Real上达92.2%，超越Seed 2.1 Pro（88.7%）；AndroidDaily上更达97.5%。

**桌面端与浏览器**：OSWorld-Verified取得79.5%的得分，仅次于Claude Opus 4.8。在OSWorld-v2上，40.0%的局部进度和13.9%的完整完成率全面压制所有开源模型，且每任务步数减少21.7%至58.4%。WebArena上73.6%的成绩超越Claude Opus 4.8。

| 模型 | MobileWorld-Real | AndroidDaily | OSWorld-Verified | WebArena |
|------|-----------------|--------------|-----------------|----------|
| Claude Opus 4.8 | 84.7 | 93.0 | 83.4 | 71.9 |
| GPT-5.6 Sol | 85.4 | 92.6 | - | - |
| Seed 2.1 Pro | 88.7 | 95.2 | 78.8 | - |
| Qwen-UI-Agent | **92.2** | **97.5** | 79.5 | **73.6** |

**GUI Grounding**：ScreenSpot-Pro zoom-in设置下81.5%的成绩领跑所有模型；UI-Vision 70.0%同样大幅超越Seed 2.1 Pro（62.0%）。通用推理与Agent能力上，相比Qwen3.5-27B基座，GUI后训练没有牺牲通用能力，Claw-Eval反而从66.9%提升至73.5%，证明GUI能力与通用能力可以兼得。

## 三、展望

Qwen-UI-Agent证明了“模型-环境-数据-训练-框架”协同设计的巨大潜力。真机闭环训练让智能体摆脱了模拟器的“温室效应”，混合行动空间开辟了更高效的执行路径。当GUI Agent真正成为连接数字世界的通用执行器，下一场交互革命或许已经拉开序幕。
