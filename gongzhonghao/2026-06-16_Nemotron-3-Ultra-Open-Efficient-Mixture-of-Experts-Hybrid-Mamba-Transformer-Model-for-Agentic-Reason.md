# NVIDIA Nemotron 3 Ultra：推理速度飙升5.9倍，开源“最速”Agent大模型

## 引言

当大型语言模型的应用从简单的聊天机器人，进化为能自主编写代码、进行深入研究和完成复杂任务的长时间运行Agent时，一个尖锐的矛盾浮出水面：模型越大越聪明，但推理速度却慢如蜗牛。Agent需要与环境进行数百次交互，每一次缓慢的推理都意味着任务失败的更高风险。现在，NVIDIA发布了其迄今为止最强大的模型——**Nemotron 3 Ultra**，以550B总参数、55B活跃参数的混合专家（MoE）架构，在一个关键维度上实现了质的飞跃：**推理吞吐量**。该模型在8K输入/64K输出场景下，推理速度最高可达同类模型的 **5.9倍**，为长时间运行的自主Agent任务提供了前所未有的效率支持。本文将从架构、训练和推理三个维度，深度解析这一里程碑式的开源模型。

## 一、核心方法：为高速Agent推理而生的架构

Nemotron 3 Ultra的核心创新在于其**混合Mamba-Attention + LatentMoE**架构。它并非简单的堆叠，而是针对推理效率进行了根本性的设计。

### 1. 混合大核：Mamba与Attention的精妙结合

传统的Transformer模型在处理长序列时，其注意力（Attention）机制的计算复杂度和KV缓存（KV Cache）会随序列长度平方增长，成为推理瓶颈。Nemotron 3 Ultra采用了**混合Mamba-Attention架构**，在模型的大部分层中使用计算高效的Mamba-2状态空间模型（SSM），仅在少数关键层（如模型的顶层和底层）中穿插稀疏的全局注意力层。

这种设计的好处是双重的：
- **Mamba层**提供随序列长度线性增长的推理速度，大幅降低了长文本解码时的计算开销和KV缓存占用。
- **稀疏的Attention层**则保留了全局信息交互的能力，确保模型在需要精确检索和长距离依赖的任务中不失准确性。

![图1：Nemotron 3 Ultra 混合Mamba-Attention层结构图](https://arxiv.org/html/2606.15007v1/x2.png)

### 2. 高效专家：LatentMoE带来的“智能”扩容

Nemotron 3 Ultra包含550B总参数，但其推理时只激活55B参数。这得益于其采用的**LatentMoE**技术。与传统的密集MoE不同，LatentMoE在专家路由路径中引入了一个低维的“潜在”投影层。

$$
\text{LatentMoE}(x) = \sum_{i=1}^{N} G(x)_i \cdot E_i(xW_{down})W_{up}
$$

其中，$x$是输入，$G(x)$是路由权重，$E_i$是第i个专家网络。LatentMoE通过投影矩阵$W_{down}$和$W_{up}$，将专家网络的输入先压缩到一个低维空间再处理，从而在保持强大模型容量的同时，显著减少了计算量。这使得每个被激活的“专家”都物超所值，实现了“用更少的算力，办更多的事”。

### 3. 视觉化数据配方：两阶段课程学习

训练数据是模型性能的基石。Nemotron 3 Ultra采用了创新的两阶段数据混合策略，完美平衡了知识的广度与深度。

![图2：训练数据混合策略示意图](https://arxiv.org/html/2606.15007v1/x3.png)

**第一阶段（前15万亿Tokens）** 侧重于**多样性**，包含大量来自网络爬虫的通用文本、代码、多种语言等数据，旨在构建宽广的知识背景。**第二阶段（后5万亿Tokens）** 则转向**高质量**，显著提高了数学、代码、法律等特定领域的高质量数据比例，旨在对模型进行精细化打磨，提升其推理和解决专业问题的能力。

## 二、后训练：Agent能力的“超级特训营”

为了让模型成为真正的自主Agent，Nemotron 3 Ultra经历了一套强大的后训练流程。其中最关键的一环是**多教师同策略蒸馏**。

在传统的强化学习中，一个模型需要独自探索并学习，效率不高。而MOPD则像请来了数十位各个领域的顶尖专家（如代码专家、搜索专家、终端操作专家），让主模型（学生模型）在“模拟考场”（即模型自己生成的轨迹）上答题，然后由这些专家教师给出每个tokens级别的精细反馈。

该过程的目标是最大化学生模型（$\pi_{\theta}$）和教师模型（$\pi^{T_i}$）分布间的负反向KL散度：

$$
\mathcal{J}_{\mathrm{MOPD}}(\theta)=\sum_{i=1}^{N}\lambda_{i}\mathbb{E}_{q\sim\mathcal{D}_{i},\;y\sim\pi_{\theta}(\cdot|q)}\left[\sum_{t=1}^{H}\log\pi^{T_{i}}(y_{t}|s_{t})-\log\pi_{\theta}(y_{t}|s_{t})\right]
$$

这种方法为学生模型提供了比稀疏的奖励信号更密集、更全面的指导，使其能快速、精准地学习各个领域的最佳实践，从而在软件工程、终端使用、搜索等Agent任务上取得显著提升。

## 三、实验：推理速度与精度的“双料冠军”

Nemotron 3 Ultra最令人瞩目的成绩体现在推理速度上。在GB200集群上，使用NVFP4精度的推理吞吐量对比结果如下：

| 模型 | 推理吞吐量 (8K输入/64K输出) |
| :--- | :--- |
| **Nemotron 3 Ultra (550B-A55B)** | **最高 (归一化)** |
| GLM-5.1-754B-A40B | ~1/5.9x |
| Kimi-K2.6-1T-A32B | ~1/4.8x |
| Qwen-3.5-397B-17B | ~1/1.6x |

![图4：精度与吞吐量对比图](https://arxiv.org/html/2606.15007v1/x1.png)

从上图可以看到，Nemotron 3 Ultra在达到与同类顶级模型同等精度的情况下，推理吞吐量实现了数倍乃至近6倍的提升。这意味着部署成本更低，响应速度更快。

在Agent任务上，Nemotron 3 Ultra同样表现强悍：

| 基准测试 | Nemotron 3 Ultra | 最佳对比模型 |
| :--- | :--- | :--- |
| **Terminal Bench 2.1** | **56.4** | 67.2 (Kimi-K2.6) |
| **SWE-Bench Verified** | **70.7** | 76.2 (GLM-5.1) |
| **PinchBench** | **90.0** | 91.3 (DS-v4-Flash) |
| **BrowseComp** | **44.4** | 61.3 (Kimi-K2.6) |

虽然在部分任务上并非绝对第一，但考虑到其相对较小的活跃参数量和极高的推理速度，Nemotron 3 Ultra在“效率-精度”的综合平衡上无疑是当前的领先者。尤其在**SWE-Bench Verified**和**PinchBench**等复杂的软件工程和工具使用任务上，其表现位列顶尖梯队，证明了其具备强大的自主Agent能力。

## 四、展望

Nemotron 3 Ultra不仅是NVIDIA自身技术实力的展现，更以开放的姿态为整个社区注入了强大动力。它将高精度与高效率完美结合，直接指向了“Agent即应用”的未来。当模型推理不再是瓶颈，我们可以期待更多真正的、能够长时间、自主完成复杂任务的AI Agent涌现。NVIDIA已经将预训练、后训练和量化后的检查点全部开源，也许下一个改变世界Agent应用的底层模型，就来自于此。
