# 港中文与NovaXBot训练Agent：LIBERO成功率73.8%！

## 一、引言

让机器人完成“把杯子放进托盘”这样的任务，难点并不只是理解指令：系统还要识别物体、选择抓取位置、控制机械臂，并在碰撞或抓空后重新尝试。

**代码即策略（Code-as-Policy，CaP）**为此提供了一条路径：让大模型根据图像编写代码，调用机器人接口，再根据执行反馈决定下一步。但现有方案往往依赖测试时调用闭源大模型，或者把抓取、放置等关键操作交给预训练技能。小型开源模型则常常连接口都用不好。

港中文与NovaXBot合作提出的**CaPtain**尝试将语言Agent常见的监督微调与多轮强化学习流程引入机器人操作：让4B视觉语言模型直接使用低层感知与运动接口，并借助仿真器中的物理状态解决长任务的奖励分配问题。

## 二、核心方法

CaPtain由执行环境、监督微调和强化学习三部分组成：环境规定模型能做什么，监督微调教会它如何交互，强化学习再根据执行结果改进操作策略。

![图1：CaPtain的执行闭环与训练流程](https://arxiv.org/html/2610.40799v1/fig1_harness.png)

### CaPtain-Harness：用低层工具建立操作闭环

Agent接收自然语言任务、接口说明以及头部和腕部相机图像，在每一轮生成Python代码，由环境执行后返回文本结果和新图像，再决定下一轮操作。每个任务最多进行60轮请求。

环境提供**22项低层能力**，包括目标分割、指点、几何测量、位姿计算、机械臂移动和夹爪控制。它不提供“抓取”“放置”这样的高层技能：抓哪里、从哪个方向接近、何时闭合夹爪，都由模型生成的代码决定。

底层仍有必要的基础设施。感知接口使用预训练模型生成分割或指点结果；运动接口负责逆运动学、自碰撞检查和力监测，在接触时按设定停止。因此，低层原语并不等于绕开感知模型或安全控制。

每次调用后，环境会返回结构化**执行回执**，例如移动停止原因、实际距离、接触力、夹爪开合状态和目标位置。模型可以据此编写条件判断、循环和重试代码。Python会话跨轮保持变量，即使对话历史被压缩，已保存的检测结果和辅助函数仍可使用。

### SFT：对齐模型与真实交互格式

基础模型选用Qwen3.5-4B。研究者先用GPT-6 Astra在同一个执行环境中生成多轮轨迹，再用这些轨迹进行**监督微调（SFT）**。

训练样本保留部署时的任务说明、工具格式、图像和回执。损失只监督模型生成的推理与代码，不把环境返回内容当作模型输出；重复执行失败或陷入恢复循环的轮次会被屏蔽。训练更新语言模型权重，视觉编码器保持冻结。

为减少模型照搬历史像素坐标的倾向，部分历史坐标会随机遮盖，迫使模型结合当前图像重新定位。完成这一阶段后，模型具备了按环境协议规划、调用工具和读取反馈的基础，再进入强化学习。

### Simulator Critic：用物理状态分配多轮奖励

机器人任务中的奖励往往在结束时才出现，但一次抓取可能涉及观察、定位、靠近和闭爪等多个请求。若只根据最终成败奖励整条轨迹，很难判断哪些决策真正改变了结果。

CaPtain采用**非对称Actor-Critic**：执行策略只能看图像和回执；训练阶段的仿真评估器（critic）则可读取策略不可见的物理状态，包括夹爪状态、物体与目标距离、子目标进度等36项特征。评估器由5个小型多层感知机组成，预测当前状态下最终成功的概率，并随策略更新持续训练。

对非终止请求，单步信用定义为：

$$
\delta_t=c_t+V_{\phi}(s_{t+1},t)-V_{\phi}(s_t,t),\qquad t<T
$$

它表示请求前后预测成功概率的变化，再加上该请求的成本；差值两端使用同一个时间索引，避免仅因时间流逝产生信用。

纯观察通常不改变物理状态，因此直接信用接近零；但观察若帮助后续抓取，仍可通过**广义优势估计（GAE）**获得后续动作传回的信用。最终优势还加入同一起始状态下多次轨迹的相对结果，用于同时比较“哪条轨迹更好”和“轨迹中的哪一步更关键”。

奖励也区分了部署所需的结束行为：成功并调用`finish()`获得1分；场景成功但未声明完成获得0.25分；在失败状态下误报完成则受到惩罚。训练还对失败动作、过多动作和任务已完成后的无效请求施加成本。

策略更新采用流式强化学习：每条轨迹最多采样8轮计算策略梯度，评估器仍使用全部状态；同时用KL约束限制策略偏离SFT模型。评估器只存在于训练阶段，测试时策略看不到仿真器的特权物理状态。

## 三、实验

训练使用LIBERO的40项任务；评估使用未参与采样的官方初始状态，以及训练中未出现的扰动。指标分为两种：**环境成功率**只检查最终场景是否满足目标，**严格成功率**还要求Agent调用`finish()`。

![图2：SFT与强化学习模型在LIBERO及扰动测试中的对比](https://arxiv.org/html/2610.40799v1/sft_vs_rl.svg)

在240个留出LIBERO测试回合中，基础Qwen3.5-4B的环境成功率为0%；SFT后达到55.4%，再经过强化学习达到**73.8%**。严格成功率则从SFT的52.1%升至67.5%。误报完成的比例从7.1%降至2.1%，平均请求数从39.1轮降至32.6轮。

这种提升也出现在扰动测试中：LIBERO-Plus的环境成功率从48.6%升至66.1%；包含动态扰动的LIBERO-MAX测试从40.0%升至61.2%。这说明相对于SFT模型，强化学习的收益没有只停留在原始测试布局上。

跨系统比较需要注意测试范围：在LIBERO-PRO的**三个短任务套件**上，CaPtain-4B达到78.5%，高于论文列出的K1、WAA和ASPIRE；加入长任务后的四套件平均值为68.6%。更高的OpenRUA在相同三套件比较中达到91.8%，因此结果并非全面领先所有前沿模型方案。

对评估器的离线分析使用了较早的9B策略轨迹：成功抓取轮次的预测成功概率变化中位数为+0.058，失败抓取为-0.0075，纯感知轮次为-0.0002。该结果支持其设计目标：让即时信用更集中于改变物理场景的操作，而不是单纯奖励较长的观察过程。

跨基准测试展示了能力与边界。未在目标域训练时，CaPtain-4B在SimplerEnv WidowX四项任务上平均成功率为83.3%；但在需要更多双臂协调的RoboTwin 2.0上为22.6%，在采用不同机械臂的RoboDojo上为0.8%。另外，受防护式运动原语限制，系统无法执行需要持续向下施力的擦拭任务。

![图3：CaPtain在真实机器人上完成物体放置任务](https://arxiv.org/html/2610.40799v1/real_robot.png)

真实机器人测试使用Astrabot XR1机械臂。由于机械臂运动学、夹爪和相机位置不同，策略先在粗略的XR1仿真环境中适配，未使用真实世界训练数据。展示的两个回合中，机器人分别完成了将黄色方块放入托盘，以及根据“天空的颜色”和“不是圆形的容器”等间接描述选择物体并放置的任务。
