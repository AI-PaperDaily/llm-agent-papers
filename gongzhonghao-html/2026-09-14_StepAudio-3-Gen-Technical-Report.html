StepAudio 3 Gen Technical Report

📅 2026-09-16

StepFun发布StepAudio 3 Gen：统一音频生成新范式，TTS与语音设计双项SOTA，人类感Elo评分1755刷新纪录

音频生成领域正经历一场从“专模专用”到“统一模型”的范式变革。过去，TTS系统专注语音保真度，音效模型只处理环境声，音乐生成则另起炉灶，各套流水线互不兼容。这种割裂让需要混合语音、音效与音乐的复杂场景难以落地。StepFun Audio团队推出的 StepAudio 3 Gen 试图终结这一局面——它用离散自回归架构替代目前主流的扩散Transformer方案，在统一框架内同时支持零样本TTS、语音设计、歌声生成、音效、音乐及混合场景，并在TTS人类感评测和语音设计指令跟随两项关键指标上达到SOTA。更值得注意的是，其架构设计围绕一个核心命题展开：如何给大语言模型装上“耳朵”和“嘴巴”，同时保住它原有的“大脑”。

一、核心方法：让LLM在离散码空间“听”与“说”

StepAudio 3 Gen的架构由两部分组成：StepAudio Tokenizer 负责将任意音频压缩为12.5Hz的离散RVQ码序列，LLM骨干网络则将这些音频码视为词汇表的自然延伸，在统一的文本-音频流中做下一token预测。整个生成过程完全在离散码空间完成，不需要扩散或流匹配渲染器。

StepAudio Tokenizer 的关键设计在于语义与声学的联合量化。它并非将语义特征和波形特征分别建模，而是将冻结SSL编码器提取的语义特征与卷积编码器提取的声学特征沿通道轴融合，经过时间压缩后送入一个共享的16×2048残差向量量化器。这意味着每一层码本都同时携带语义信息与声学细节，而非专属于单一模态。训练中使用0.5的quantizer dropout率，驱动低层码本集中编码粗粒度语义规划信息，深层码本逐步精化声学细节。推理端则采用因果解码器，配合25帧滑窗注意力，支持低延迟流式合成。

LLM骨干部分的设计更为激进：只有第0层码本（$c_{t,0}$）进入主语言模型的词汇表和输出头，其余15层残差码本由一个独立的四层因果Transformer——RVQ Code Predictor——沿码本深度轴自回归生成。给定骨干网络在音频位置的隐藏状态$\mathbf{z}_t$和刚选出的$c_{t,0}$，该预测器依次输出$c_{t,1}$到$c_{t,15}$。这一时间-深度分离的因子化设计将长程规划任务交给LLM，将高频声学细节建模限制在小模块内，避免了将所有16层码本摊平到时间轴上导致的序列长度爆炸。

创新点一：RVQ Adaptor——多码本嵌入的“翻译器”

16层码本各有独立嵌入表，求和后的帧嵌入在统计分布上与预训练文本嵌入存在显著偏移。直接注入LLM会迫使骨干网络在前几轮优化中耗费大量参数容量去“消化”音频表示的统计差异。论文提出的 RVQ Adaptor 是一个零初始化、逐token的残差模块，其输出的下投影层初始化为零，因此模块在初始化时是一个精确的恒等映射。它对求和后的16层音频嵌入做模态特定的空间变换，只在音频位置以元素相加方式注入LLM输入流，文本位置完全不受影响。这相当于给音频输入装了一个“翻译器”，先将其映射到LLM熟悉的输入空间，再交给共享骨干处理。

创新点二：干扰感知的渐进式预训练

给预训练LLM添加音频能力面临双重干扰：一是新初始化的RVQ嵌入对文本嵌入统计的冲击，二是15层残差码本的梯度规模远大于token级损失，可能重塑骨干表征。论文的四阶段预训练策略直接针对这两条干扰通道：

  • Stage 1（模态对齐）：冻结骨干网络，只训练音频嵌入和RVQ Adaptor，仅用ASR和语音翻译任务，文本能力零漂移。
  • Stage 2（音频理解）：解冻全模型，音频理解任务与文本语料1:1混合训练，仍不监督音频生成目标。
  • Stage 3（生成，梯度分离）：引入TTS和语音对话，但RVQ Code Predictor的隐藏状态前缀与LLM骨干之间被切断梯度（stop-gradient）。此时15层残差码本的损失只训练预测器本身，LLM骨干仅由token级目标驱动。
  • Stage 4（长上下文联合冷却）：解除梯度分离，以更低学习率（$2\times10^{-5} \to 1.5\times10^{-5}$）和更长序列（32768）进行端到端联合训练，同时将$\lambda$从1.0降至0.1，将深度损失与token损失的梯度规模拉平。

创新点三：统一指令格式下的场景编排

模型通过ROLE / DIRECTOR / SCRIPT三字段指令格式组织请求。ROLE定义说话人身份与音色特征，DIRECTOR描述声学场景与生成意图，SCRIPT则沿时间轴排列语音和音效事件——每个口语段前加说话人标签和可选的(描述)标记，音效和音乐以[描述]条目表示。这种设计允许单条指令定义多个角色及其关系，同时指定音色、风格、情绪、口音，以及音效与背景音乐的时序排布。

二、实验：双重SOTA与文本能力的保留

实验部分首先验证了两个核心设计假设。RVQ Adaptor的消融实验结果显著：装备该模块后，AISHELL-1 CER从5.25%降至3.00%，LibriSpeech WER从6.00%降至3.41%，MMAU音频理解准确率从40.70%跃升至51.70%，CoVoST中英双向翻译BLEU分别从12.05/5.99提升至30.56/18.59，SpeechMMLU T2S准确率从12.13%飙升至58.76%。这一全面领先表明，多码本音频嵌入与LLM输入空间的适配是整合成功的关键前提。

在文本能力保留方面，与缺少RVQ Adaptor的三阶段基线相比，干扰感知渐进式预训练在全部七个文本基准上实现一致提升：FinEval +5.82pp，C-Eval +5.58pp，MATH +8.45pp，HumanEval Pass@1从47.56%升至54.27%。这一结果直接验证了“冻结对齐—文本混合—梯度分离—低速联合”四阶段策略的有效性。

TTS评测采用Arena式人类主观对比，判定标准是“哪个更像真人自然说话”。在1500次成对比较中，StepAudio 3 Gen取得Elo 1755.33，超越五款商用竞品（Qwen-Audio-3.0-TTS-Plus、Doubao-App、MiniMax-Speech-2.8-HD、Inworld-TTS-2、StepAudio 2.5 TTS），且对每个对手的胜率均不低于73%，总胜率82.0%。

语音设计评测在InstructTTSEval全量基准上进行。该基准包含2000条中英文文本，在声学参数规格（APS）、描述风格指令（DSD）和角色扮演（RP）三种条件下共生成6000条语音，由Gemini 3.1 Pro判定风格一致性。StepAudio 3 Gen在中文平均得分85.2%，英文77.7%，均排名第一。在人类盲评中同样以Elo 1668.5领先，对单个对手的胜率区间为65.3%至85.7%。

三、展望

StepAudio 3 Gen的实践意义在于提供了一个可复用的“LLM音频化”路线图：共享语义-声学RVQ表示、时间-深度因子化生成、以及以梯度分离为核心的干扰抑制策略，三者组合使得离散自回归方案在通用音频生成上足以正面对抗扩散方案。当TTS的评测标准从“内容对得上”升级为“像不像真人说话”时，模型对副语言现象和自然韵律的捕捉能力成为新的竞争壁垒。未来，统一的离散音频表示能否反向增强LLM的语音理解能力，甚至催生真正意义上的端到端语音-语音Agent，值得持续观察。
