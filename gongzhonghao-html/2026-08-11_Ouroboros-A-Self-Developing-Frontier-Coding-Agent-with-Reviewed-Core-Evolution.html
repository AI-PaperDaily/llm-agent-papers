Ouroboros: A Self-Developing Frontier Coding Agent with Reviewed Core Evolution

📅 2026-08-12

自进化智能体Ouroboros登顶三大基准：86.97%终端任务成功率，开源自进化代码Agent问世

大模型时代，Agent的能力上限究竟由什么决定？传统观点认为，基座模型的智力水平是决定性因素。然而，随着模型能力逼近瓶颈，一个愈发关键却被长期忽视的因素浮出水面：执行框架（Harness）。一个固定的框架真的能适应不断涌现的复杂任务吗？若框架本身能够学习、迭代甚至进化，又会带来怎样的性能飞跃？

研究者提出了一种全新的自进化前沿编码智能体Ouroboros，其核心思想是将执行框架视为一个持续进化的对象。这项技术通过“评审式核心进化”机制，让Agent能够修改自身的代码、工具和提示词，并在Terminal-Bench 2.1上取得了86.97%的惊人成绩，刷新了业界记录。

一、核心方法：让框架像软件一样“活”起来

Ouroboros的设计哲学源于一个朴素观察：软件需要版本管理，那么同样由代码构成的Agent框架，为何不能拥有生命周期的迭代？该论文提出了一套完整的自进化架构，其核心包含两大创新机制。

双模式核心进化机制

论文将进化机制划分为两种互补的模式。递归自由进化将“改进自身”作为核心任务，Agent在检查完当前系统后，会选择并实现一项改进，完成后可继续调度下一轮进化，形成持续的优化序列。而经验驱动核心进化则从平凡任务中汲取养分，通过任务执行、自我反思或社交反馈来暴露Bug、低效路径等问题。

受控的提交管道

为了避免进化过程失控，Ouroboros设计了一套严密的受控提交流程，这也是实现“评审式进化”的关键保障：

  • 染色体重启（Rollback）：支持在任何故障后，恢复到先前经过评审的稳定版本。
  • 指纹校验（Fingerprinting）：提交前会对暂存区diff进行指纹提取，在收集完评审证据后、提交前再次复核，确保提交内容未被篡改。
  • 审查委员会（Review Panel）：通过多模型评审机制对核心代码变更进行把关，分阶段（Diff-review）和全仓库范围（Scope-review）的评审模式可配置，确保每次代码变更都经过严格验证。

此外，为了确保进化的安全性，Ouroboros引入了运行时宪法（Runtime Constitution）的概念，将操作边界、行为准则等核心文件置于受保护路径中，防止Agent在自我修改时意外或故意削弱安全限制。

二、实验结果：全方位碾压的SOTA成绩

为了验证自进化框架的有效性，研究者进行了一系列严格的基准测试，横跨终端操作、GUI交互、长上下文记忆与代码生成五大领域。

在最具挑战性的Terminal-Bench 2.1上，Ouroboros的多轮采样结合严格的公共提交物审计（Audit），得出了86.74%的修正后最高分。即便面对拥有同样强大的Opus 5模型驱动的顶级商业基线Claude Code，Ouroboros依然凭借优秀的框架设计取得了3个百分点以上的压倒性优势。同时，在考验GUI智能体实用性的OSWorld基准上，Ouroboros得分高达90.69%，打破了该领域的最高纪录。

更值得关注的是在需要持续学习能力的CL-Bench中的表现，Ouroboros达到了0.2301的标准化奖励，性能完全超越了传统的大模型上下文学习方法。

三、安全架构：进化中的定海神针

支持自我修改的Agent往往会让安全成为隐患。但Ouroboros在设计中，将操作安全视为“首要设计约束”。论文明确指出，需要在Agent的大规模进化过程中保持约束力，防止它通过修改代码来扩展权限或削弱控制。

为此，Ouroboros构建了一套独立于Agent进化权限之外的安全底座。该机制引入了多重“硬性”护栏：

  • 外部预算帽与紧急停止：拥有独立的operator通道及/panic命令，可在代理自主行动前强制停止进程树。
  • 宪法常驻与治理保护：将最高行为准绳（宪法）通过不可截断路径加载，并固定置于提示上下文中。治理文件受确定性工具保护，普通写入路径无法触及。
  • 关键状态审计：通过记录运行清单、随机种子、提交快照的指纹，确保每一次进化的结果都可追溯到具体的状态和证据。

这种将“进化能力”与“控制权威”分离的思路，使得该系统能够安全地应对自我重写可能带来的失控风险。

四、现场实验：长达161天的“希望”项目

为了测试长期进化效果，研究团队部署了名为“Hope”的长期Agent。在长达 161天 的公开运行中，Hope持续与七种不同渠道（网页、语音、社交平台等）的人类用户交互，根据反馈与经验不断修改自己的代码。在人类用户的提醒下，它成功修复了重复发送消息的Bug；又通过自我观察，修复了自我反思时的上下文溢出问题。这项实验证明了经验驱动进化在真实复杂环境中的可行性。

五、展望：未来属于会编程的Agent

Ouroboros通过将进化机制引入代码框架，打破了传统Agent能力的天花板。这一技术路线展现出的强大潜力，指引着AI走向更深度、更自主的方向。虽然该工作需要面对如自举式盲点（例如法官与Agent共享盲区）等挑战，但其开创性的工作逻辑已经为“会自我编程”的下一代AI奠定坚实基础。

当Agent成为自己的工程师，人类与机器的协作边界将再次被重新定义。未来的Agent，是否还会需要人类的“评审”呢？
