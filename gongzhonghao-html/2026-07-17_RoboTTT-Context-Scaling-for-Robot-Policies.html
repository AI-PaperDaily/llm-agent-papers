RoboTTT: Context Scaling for Robot Policies

📅 2026-07-20

NVIDIA与斯坦福联合提出RoboTTT：将机器人策略上下文长度扩展至8000步，性能飙升87%！

引言

想象一下，一个机器人需要完成一个长达五分钟、包含十个阶段的组装任务。在现有的技术水平下，这样的长时域、多阶段操作几乎是不可完成的任务——大多数机器人基础模型只能处理单步或极短的历史视觉运动上下文，如同一个只能看到眼前一步的棋手。

这种能力上的巨大鸿沟，正是当前机器人策略面临的核心挑战。虽然大语言模型已经把上下文长度作为关键的缩放轴，但在机器人领域，如何让策略从任意长度的历史中学习和利用信息，仍然是一个悬而未决的问题。论文提出了一种全新的解决方案——RoboTTT（Test-Time-Training Robot Policies），通过将测试时训练机制融入机器人基础模型，成功将视觉运动上下文扩展到8000个时间步，并在多个极具挑战性的操作任务上实现了突破性性能提升。

一、核心方法：RoboTTT

1. 突破上下文的瓶颈：测试时训练机制

传统机器人策略在处理长序列时面临三个核心挑战：编码历史信息的容量不足、难以有效利用上下文、以及推理成本随上下文长度线性增长。RoboTTT通过引入测试时训练（TTT）机制，优雅地解决了这些问题。

该机制的核心是快权重与慢权重的区分。慢权重是传统的模型参数，仅在训练时更新；而快权重则在训练和推理过程中都通过梯度下降动态更新，用于编码和检索上下文信息。论文将该机制形式化为以下过程：

$$W_t \leftarrow W_{t-1} - \eta \nabla_W \mathcal{L}_{\text{FW}}\left(f_{W_{t-1}}\left(K_t\right), V_t\right)$$ $$O_t = f_{W_t}(Q_t)$$

其中，$W_t$是时间步$t$的快权重，$\eta$是可学习的学习率，$\mathcal{L}_{\text{FW}}$是均方误差损失函数，$f_W$是由快权重参数化的小型神经网络。这种“先更新后应用”的操作实现了对上下文信息的压缩和检索，同时保持推理成本恒定。

2. 模型架构：TTT层与注意力层的协同

RoboTTT在GR00T N1.7的基础上构建，创新性地将TTT层集成到Diffusion Transformer（DiT）动作头中。架构的一个关键设计是：注意力层在单个时间步内处理信息，而TTT层则跨时间步处理信息。这种分工避免了传统方法中简单拼接历史帧带来的虚假相关性。

RoboTTT的DiT输入是一个跨T个时间步的机器人轨迹序列，包括视觉语言token、本体感知token、噪声动作token和学习到的注册token。为了保留预训练模型的知识，论文采用了$\tanh$门控机制：

$$O = \tanh(\alpha) \odot O_{\text{TTT}} + O_{\text{attn}}$$

其中，$\alpha$在训练开始时初始化为接近零的值，使TTT层的贡献逐渐增加，而不会冲垮预训练模型的计算。

3. 序列训练：TBPTT与序列动作强制

为了在有限GPU内存下训练长序列，RoboTTT采用了截断式反向传播（TBPTT）。输入序列被划分为片段，梯度仅在片段内流动，但快权重跨片段边界传递，使TTT能在整个序列上持续进行。这种设计使训练上下文长度可以任意扩展，而GPU内存由片段长度决定。

论文还提出了序列动作强制技术：在序列训练中，为每个动作块独立采样噪声级别。这避免了在序列级别共享统一噪声带来的训练不稳定问题。训练目标被定义为：

$$\mathcal{L}_{\text{fm}}\left(\xi; W_0\right)=\frac{1}{T}\sum_{t=1}^{T}\mathbb{E}_{\tau_t, \epsilon}\left[\left\|v_\theta\left(\Phi_t, A_t^{\tau_t}, q_t; W_{t-1}\right)-\left(A_t-\epsilon\right)\right\|^2\right]$$

4. 从上下文中学习：视频示范模仿与DAgger蒸馏

RoboTTT最具创新性的能力之一是从上下文视频示范中进行一次模仿。通过将人类视频演示与机器人轨迹配对，并仅在机器人轨迹部分计算动作损失，模型学会从上下文视频中提取任务信息。在测试时，只需提供一个单一人类视频，就能实现未见任务配置的一次模仿。

此外，论文提出了DAgger蒸馏方法，将人类干预的纠正过程蒸馏到快权重中。在序列训练中，所有执行的子优机器人动作都用于更新快权重（作为上下文），但流匹配损失仅计算在人工纠正动作上。这种不对称设计使模型能够学习从失败到纠正的映射，在部署时实现在线策略改进。

二、实验：突破性性能表现

1. 长时域多阶段任务

论文在三个极具挑战性的组装任务上评估了RoboTTT：Pup Go Car（平均2分钟）、Circuit（1分钟）和Gear Bot（5分钟，10个阶段）。实验结果令人瞩目：

RoboTTT在所有任务上全面领先：平均任务完成分数达到79%，比单步上下文基线GR00T N1.7（42%）高出87%，比最佳基线GDN（56%）高出41%。更令人印象深刻的是，在Gear Bot任务上，RoboTTT在10次试验中实现了2次完全成功，而所有基线方法均以失败告终。

2. 上下文的缩放效应

论文首次展示了一个重要发现：预训练上下文的缩放能带来闭环性能的持续提升。

当预训练上下文从128时间步增长到8000时间步时，RoboTTT的性能从约44%提升至71.5%，提升幅度达63%，且没有出现饱和迹象。相比之下，GDN等线性复杂度的循环记忆模型并未从更长的上下文中受益。这表明，上下文长度可能成为机器人基础模型的新缩放轴。

3. 一次模仿与扰动鲁棒性

在Circuit任务上的一次目标模仿实验中，RoboTTT在10次试验中成功完成了6次组装，而GDN完全失败。这说明尽管循环记忆策略可以编码上下文信息，但难以有效利用；而RoboTTT通过梯度下降更新的快权重，能够在需要时准确检索演示的配置信息。

在外部扰动鲁棒性测试中，RoboTTT在屋顶扰动下成功恢复率为75%（15/20），在轮胎扰动下达到90%（18/20），大幅超越短上下文基线。

4. DAgger蒸馏的效果

DAgger蒸馏方法带来了显著的性能提升：从相同的DAgger数据中，RoboTTT提升了36%，而标准DAgger训练仅提升13%。子优机器人动作的价值不在于作为模仿目标，而在于作为上下文，使模型能够学习故障-纠正映射，在运行时实现真正的在线策略改进。

三、展望

RoboTTT的出现，标志着机器人策略从“短视”向“长视”的重要转变。通过将测试时训练机制与机器人基础模型深度整合，论文实现了视觉运动上下文从数十时间步到数千时间步的跨越式扩展。这一突破不仅展现了上下文缩放作为机器人基础模型新缩放轴的巨大潜力，也为机器人一次模仿学习、在线策略改进和长时域复杂任务的执行开辟了全新可能。随着相关训练技术的进一步优化，有理由期待：下一个五年，机器人将不再是只能简单执行指令的工具，而是能够在实践中不断学习、适应和进化的智能体。
