LLM-as-a-Verifier: A General-Purpose Verification Framework

📅 2026-07-08

斯坦福&UC Berkeley提出LLM-as-a-Verifier框架：验证缩放实现SOTA性能，Terminal-Bench V2达86.5%

当大模型在生成能力上不断通过预训练、后训练和测试时计算实现“规模法则”时，一个关键却常被忽视的问题浮出水面：模型能否学会验证自己答案的正确性？ 研究者们指出，验证能力是一个全新的、独立的缩放轴。传统的“LLM作为裁判”方法通常只输出离散的分数，这不仅导致粗粒度的评分，而且在面对复杂解决方案时极易出现平局，无法有效区分优劣。

为了解决这个根本性难题，来自斯坦福大学、UC Berkeley和NVIDIA Research的联合团队提出了一种全新的通用验证框架——LLM-as-a-Verifier。该框架无需额外训练，通过利用评分token logits的完整概率分布来生成连续分数，使得验证能力可以沿着多个维度进行缩放。实验数据显示，该方法在Terminal-Bench V2、SWE-Bench Verified、RoboRewardBench和MedAgentBench四大基准上均取得了新的最先进（SOTA）性能，分别达到了86.5%、78.2%、87.4% 和73.3%。

一、核心方法：从“裁判”到“验证者”的范式转变

传统方法通常将LLM作为裁判，要求其输出单个离散分数（例如1-5分）。这种方式忽视了模型内部对其判断的不确定性，导致评分坍缩。LLM-as-a-Verifier的核心洞察在于：将评分从寻找“最可能的token”转变为计算“期望分数”。

1.1 概率化的连续反馈

该框架不再直接获取单一打分token，而是提取模型在输出特定评分token（如数字1到20）时的完整logits分布。通过计算所有可能token的期望值，得到一个连续的奖励信号。这种连续的本质为后续的多维度缩放奠定了基础。

1.2 验证的三大缩放轴

论文明确提出了验证能力可沿三个独立且互补的维度进行缩放，这是该工作的核心理论贡献。

1. 评分粒度放大（Scale Score Granularity）：
传统离散评分将模型的内部信念四舍五入成整数。通过使用更多、更细粒度的评分token（例如从5级放大到20级），模型能够在一个更精细的“投影空间”内表达其评估。研究表明，增加评分粒度显著提高了信噪比（SNR），即正确与错误轨迹得分差距相对于噪声的比例，从而更可靠地分离优劣解。

2. 重复评估降噪（Scale Repeated Evaluations）：
单次评估可能受到提示词或特定失败模式的偏差影响。通过多次独立评估并取平均，可以有效地降低方差，使评估结果更加稳健。该机制如同蒙特卡洛估计，方差随评估次数（k）的增加而呈现出$O(1/k)$的下降趋势。

3. 评判标准分解（Scale Criteria Decomposition）：
面对复杂的Agent任务（如代码生成），单一笼统的评判标准（如“这个轨迹正确吗？”）容易误导模型。论文提出将复杂标准分解为更易于验证的子标准，例如针对代码Agent，将其分解为“是否满足规范”、“最终输出格式”、“是否无报错”三个独立子标准。最终奖励是各子标准期望分数的平均，这有效降低了提示词偏差。

为了选择最佳轨迹，论文还设计了一种高效的“概率化枢轴锦标赛”算法。该算法通过一系列成对比较，能在有限的验证预算下，将复杂度从$O(N^2)$降至$O(Nk^2)$，从而实现成本可控的最佳解筛选。

1.3 核心公式

验证框架的核心数学表达如下：

$$R(x,\tau)=\frac{1}{CK}\sum_{c=1}^{C}\sum_{k=1}^{K}\sum_{g=1}^{G}p_{\theta}(v_{g}\mid x,c,\tau)\,\phi(v_{g})$$

这里，$C$代表评价标准的数量，$K$是重复评估的次数，$G$是评分token的粒度。$p_{\theta}(v_{g})$是模型对某个评分token的概率，而$\phi(v_{g})$将其映射为标量。该方法通过多重求和实现了精准的连续评分。

二、实验：跨领域的全面胜利

研究者们在四个具有代表性的基准上对LLM-as-a-Verifier进行了全面评估，覆盖了编码、机器人学和医学三个极具挑战性的领域。在所有实验中，该框架均无需任何特定领域的微调，直接作为即插即用的验证器，取得了令人瞩目的结果。

2.1 编码与软件工程

  • Terminal-Bench V2：在Shell环境中的长时多步推理任务上，LLM-as-a-Verifier超越了GPT-5.5、Claude Opus 4.7等前沿模型，达到了86.5% 的SOTA准确率。
  • SWE-Bench Verified：处理真实世界GitHub Issue的任务。该框架从包含不同模型生成轨迹的混合池中，成功识别并选择了最佳解决方案，准确率提升至78.2%，超过单模型Pass@1的水平。

2.2 机器人学

  • RoboRewardBench：用于评估机器人操作轨迹的奖励模型。该框架表现惊人，偏好准确率达到87.4%。相比之下，经过数十万乃至百万级数据训练的专用奖励模型（如RoboReward-8B、Robometer-4B）分别只达到了81.4%和78.8%。此外，该框架还能作为任务进度的代理，其生成的分数与机器人任务完成度呈现极高的Spearman等级相关性（VOC），高达0.966。

2.3 医学

  • MedAgentBench：在模拟电子健康记录环境中，LLM-as-a-Verifier再次稳定提升性能，达到了73.3%，击败了Claude Opus 4.8、GPT-5.5等强大的基线模型。

三、展望：开启强化学习的新范式

LLM-as-a-Verifier的价值远不止于测试时的择优。研究者进一步发现，其生成的高精度细粒度信号可以作为一种密集奖励信号，用于强化学习。

在一个扩散策略的强化学习中，使用该框架的奖励进行微调，实现了*约1.8倍*的样本效率提升，最终成功率也超过稀疏奖励基线。在数学推理上，作为Group Relative Policy Optimization（GRPO）的补充奖励，也稳定带来了约1.1倍**的效率提升。

这项研究揭示了一个巨大的潜力：在一个Agent系统中，制约其能力上限的往往不是生成能力，而是鉴别能力。LLM-as-a-Verifier不仅为“如何更好地挑选最优方案”提供了通用解法，更让模型在自我改进的强化学习循环中，能够更有效地利用每一次试错经验。对于开发者而言，这或许意味着，将大模型从“更好的写手”培养为“更严苛的考官”，是通往通用人工智能的关键一环。
