Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents

📅 2026-07-11

Meta AI提出“主动记忆代理”：长程Agent决策失误率降低8.3%，精准干预决胜关键节点

痛点直击：长程任务中，Agent的“记忆走了样”

在复杂的多轮工具调用、命令行操作或对话交互场景中，大型语言模型Agent常常表现出一种令人困惑的“忘性”：在一个长达数十步的任务中，Agent可能在前几轮明确识别了某个系统环境限制或任务硬性要求，却在后续的调试过程中完全忽略，导致反复尝试同样的失败路径。

这种信息存在于历史轨迹中，却无法持续影响当前决策的现象，论文作者将其定义为 ”行为状态衰减”（Behavioral State Decay） 。这不是简单的上下文长度限制问题——即便信息仍然停留在模型窗口内，它对行为的影响力也在逐步消失。传统记忆系统侧重于存储与检索，却无法回答一个关键问题：何时应该让记忆重新进入决策回路？

Meta AI的研究团队在代码仓库中公开了名为 Proactive Memory Agent 的解决方案。在Terminal-Bench 2.0和τ²-Bench两项基准测试中，该方法为Claude Sonnet 4.5带来了高达+8.3个百分点的性能提升，即便是更强大的Claude Opus 4.6也获得了约+2.5个百分点的增益。

一、核心方法：记忆干预的两阶段架构

1. 记忆代理：一个“会思考”的监控者

论文提出的核心思想是 将记忆视为一种干预策略，而非被动的内容仓库。研究者设计了一个独立的记忆代理，与原始的动作代理并行运行。这个记忆代理不会被直接调用来回答问题或提供指导，而是以固定间隔（论文设定为每N步）被激活，完成两个关键阶段的工作。

上图展示了系统架构：左侧是动作代理与环境的直接交互，右侧是记忆代理的监控与干预流程。记忆代理观察最近8轮的轨迹片段，根据当前记忆库状态决定是否注入提醒。

2. 结构化的记忆库：状态、知识与程序三种维度

传统的记忆系统往往只做简单的段落式存储，而该项目将记忆组织为三个独立组件：

$$B_t = (s_t, K_t, P_t)$$
  • 状态字段：记忆代理私有的进度追踪信息，永不暴露给动作代理，用于内部决策参考。
  • 知识记忆：存储任务中相对稳定的环境事实，如文件路径、API细节、系统约束等。
  • 程序记忆：记录尝试与结果，包括已失败的命令、成功的修复方案、已排除的假设等。

记忆库通过四种标准化工具调用进行维护：memory_update_status、memory_save_knowledge、memory_save_procedural和memory_delete。这种结构化的设计让记忆库能够在长程任务中保持清晰且易于更新。

3. 选择性的干预决策：沉默本身就是一种策略

完成记忆库更新后，记忆代理进入第二阶段——干预选择。它需要回答一个更微妙的问题：当前记忆中的哪一项值得立刻注入到下一轮动作决策中？

为了实现这一目标，记忆代理的输出只有两种可能：要么生成一个指定的文本提醒，要么选择保持沉默（无干预）。这个机制通过以下数学形式表达：

$$B_t \sim \pi_M^{\text{edit}}(\cdot | x, w_t, B_{t-1})$$ $$i_t \sim \pi_M^{\text{intervene}}(\cdot | x, w_t, B_t)$$

其中 $i_t \in \{\emptyset, \text{text reminder}\}$，$w_t$ 表示最近轨迹窗口，$B_t$ 表示当前记忆库。论文强调，空干预是一个显式决策，而非默认行为。记忆代理被鼓励仅在记忆可能显著影响下一动作决策时才介入，避免不必要的令牌消耗或注意力分散。

二、基准实验结果：性能提升的量化验证

1. 主要对比结果

论文在两个长期任务基准上进行了严格评估：

基准 动作模型 基线 +记忆代理 增益(pp)
Terminal-Bench 2.0 Sonnet 4.5 37.6% 45.9% +8.3
Terminal-Bench 2.0 Opus 4.6 43.5% 45.9% +2.4
τ²-Bench（加权平均） Sonnet 4.5 55.0% 61.8% +6.8
τ²-Bench（加权平均） Opus 4.6 66.2% 68.7% +2.5

论文作者指出，性能提升不仅体现在较弱的模型上，即便是更强的Opus专业模型也获得了增益，说明记忆干预的价值并非单纯弥补模型能力局限。

2. 关键消融实验

为了验证两阶段设计的必要性，研究者进行了系统的消融对比：

变体 功能配置 宏观平均(%)
Sonnet 4.5基线 无记忆干预 57.5
全记忆代理（论文方案） 有库管理+选择性干预 64.3
全库暴露 有库管理+无选择性 61.5
始终注入 有库管理+每轮注入 63.5
无库注入（类似顾问模式） 无持久库+选择性干预 61.0
Mem0检索 通用检索+向量搜索 62.1

这些数据揭示了一个清晰的结论：移除任何一个功能组件都会导致性能下降。最接近理想状态的是“有库管理+选择性干预”的组合，说明记忆代理必须既懂得保存什么，也懂得什么时候不说话。

3. 学习记忆启发的初步探索

作为对开源模型方向的探索，研究者使用Qwen3.5-27B作为可训练的记忆代理，固定Qwen3.5-122B-A10B作为动作代理，在SETA训练集上进行监督微调和GRPO强化学习：

训练阶段 验证奖励 Terminal-Bench(Pass@1) 增益
无记忆 0.709 37.6% —
Base 27B 0.693 — -0.016
SFT训练 0.720 — +0.011
GRPO训练 0.734 41.1% +3.5pp

有趣的是，未训练的Base模型反而降低了基准分数，而监督学习恢复了损失，强化学习则进一步提升了校准效果。这表明记忆代理的核心能力——决定何时介入——可以通过强化学习进行有效训练。

三、技术启示与未来展望

该项目提出的主动记忆干预理念，为长程Agent的稳定性和一致性提供了一个新的设计范式。研究团队已开源完整代码，允许社区在任意的动作代理框架上进行即插即用的集成。

从论文的定性分析来看，记忆代理成功的关键时刻往往发生在动作代理即将做出错误决策的“临界点”：当它准备忽视已验证的环境限制时，当它重复尝试已证明无效的路径时，当它忽略了某个关键的系统约束时。正因如此，研究者强调校准时机比校准记忆内容更为重要。

对于希望构建真正可靠、自主的长程Agent的开发者来说，这可能是一个值得深入了解的方向：智能不仅仅是懂得更多，更是在正确的时刻提醒自己什么是最重要的。
