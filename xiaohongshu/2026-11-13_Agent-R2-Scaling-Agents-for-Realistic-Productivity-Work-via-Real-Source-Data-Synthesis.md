4B模型GDPval得分涨18.6分

今天给大家带来浙大、百度的Agent-R2：用真实工作流程和文件合成训练数据，让小模型更擅长完成办公任务。

🔑关键方法

1️⃣ 挖掘工作流：以职业活动为线索，从网页语料中提取需要读取、处理和生成文件的工作流程。

2️⃣ 构造任务：检索并验证真实附件，再结合文件内容生成任务指令和细粒度评分标准。从1万条语料候选中得到4000个任务。

3️⃣ 两阶段训练：用3000条专家轨迹做监督微调（SFT），再用1000个不重叠任务做基于评分标准的强化学习（RL），优化最终交付质量。

💡核心创新

1️⃣ 不靠模型凭空生成办公附件，而是引入真实多格式文件，保留复杂排版、内容缺漏和跨文件依赖。

2️⃣ 不只判断“文件有没有生成”，还按证据、计算和格式等细项评价交付物，减少Agent没查清数据就匆忙交稿的“走捷径”行为。

📊实验效果

✅ GDPval全量集：Agent-R2-4B的Pass@1得分从基座模型的32.4%升至51.0%，提高18.6个百分点；Qwen3-235B对应得分为48.0%。

✅ OfficeQA：Agent-R2-4B的Pass@1从基座模型的2.2%升至14.8%，高于Qwen3-235B的13.8%。

✅ 行为分析：经过RL后，交付物复查率从基座模型的0.5%升至95.8%，未修复错误就继续生成的比例从55.0%降至11.0%。

✅ 消融实验中，使用真实文件训练的模型GDPval得分为43.3%，高于使用合成文件的41.4%。不过，论文也使用了更强的模型生成专家轨迹和评分，小模型效果离不开这套数据与训练流程。
