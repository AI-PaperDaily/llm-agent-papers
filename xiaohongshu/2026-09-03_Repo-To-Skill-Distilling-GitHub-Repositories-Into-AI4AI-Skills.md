DisCo给Agent外挂技能库

今天给大家带来一篇把GitHub仓库“蒸馏”成Agent可复用技能的工作，它补齐了大模型研究Agent最缺的“操作知识层”——就是那种知道方法但一跑就崩的经验空白。

🔑关键方法
1️⃣ 技能三层封装：每个技能由SKILL.md知识接口、references/知识底料、scripts/执行接口组成，Agent按需渐进加载，不会一次性爆上下文。
2️⃣ 四阶段蒸馏管线：scope确定能力、ground提取证据、construct构建技能图、verify验证修复；同时支持任务无关（提前蒸馏仓库）和任务导向（按任务现造技能）两种模式。
3️⃣ 技能图谱加路由：单个仓库蒸馏成技能图，库级router按20个领域、178个能力族定位，研究时只读相关分支，避免无关信息干扰。

💡核心创新
1️⃣ 把“操作知识”从模型和harness里独立出来，变成第三层，专门解决研究Agent反复试错烧预算的问题。
2️⃣ DisCo同时具备creator和researcher双模式，造技能必须先验证后入库，不是简单摘要，而是带证据和失败记录的可追溯技能。
3️⃣ 规模化落地：AREX-Skill库从1000个常用ML仓库蒸馏出5000+验证技能，覆盖20领域178能力族，形成可复用的外部知识底座。

📊实验效果
✅ MLE-bench：同样GPT-5.5 Codex，加技能后Any-Medal从31.11%升到72.89%，相对提升134.3%，High难度任务从13.33%拉到62.22%。
✅ PaperBench：复现平均分从29.45%升到39.59%，相对+34.4%，20个任务里18个有提升，rice单任务提升40.57个点。
✅ FrontierCS：188个Agent Track任务分数从70.63升到77.14，相对+9.2%，低分任务平均拉高26.56分。
✅ PassNet：AS Score从1.343升到1.5313，相对+14.0%，失败样本减少64.3%，还超过了TorchInductor。

整体思路很直接：把散落在仓库、论文里的操作经验压缩成小颗粒技能，Agent用的时候只挑需要的看。而且这些提升是在模型、harness和执行预算完全不变的情况下拿到的，变量只有技能。
