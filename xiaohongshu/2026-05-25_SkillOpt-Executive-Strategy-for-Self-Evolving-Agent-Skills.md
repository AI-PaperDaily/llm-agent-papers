Agent技能也能“训练”？SkillOpt来了

今天给大家带来一个让Agent像神经网络一样“训练”技能的新框架SkillOpt。它把技能文档当作可优化的外部状态，用一套严谨的文本空间优化器来迭代改进，彻底告别手动写prompt或盲目自修改。

🔑关键方法
1️⃣ 边界文本更新（textual learning rate）  
每次只允许有限数量的新增/删除/替换操作，类似深度学习中的学习率控制，防止一次改动过大破坏已有能力。配合余弦衰减调度，前期大改、后期精调。

2️⃣ 验证门控（held-out validation gate）  
每次修改后的技能必须在留出验证集上严格优于当前技能才被接受，拒绝的编辑自动记录到“失败缓冲”中，后续优化时作为负反馈避免重复踩坑。

3️⃣ 慢更新/元更新（epoch-wise slow/meta update）  
每轮训练结束后，对比上一轮和当前轮技能的表现，提炼出跨epoch的持久性规则，存入受保护的慢更新字段，确保长期稳定的知识积累。

💡核心创新
1️⃣ 将Agent技能视为可训练的外部状态  
首次把技能文档当作深度学习中的权重一样对待，训练过程有batch、epoch、学习率、验证、动量等完整闭环。目标模型完全冻结，零推理开销。

2️⃣ 分离目标模型与优化器  
优化器只在训练时调用（可用更强模型），训练出来的best_skill.md是纯文本，部署时只需占用几百到两千token，不消耗额外算力。

3️⃣ 技能可迁移、可审计  
优化后的技能文档极小（典型300-2000 token），且可跨模型、跨执行环境（Codex/Claude Code/直接对话）、跨基准（如数学竞赛到另一数学基准）直接使用，均能带来正向收益。

📊实验效果
✅ 在6个基准、7个目标模型、3种执行模式下，共52个（模型,基准,执行环境）测试单元格中，SkillOpt全部获得最佳或并列最佳。  
✅ 在GPT-5.5上，无技能基线平均58.8%，使用SkillOpt后提升至82.3%，平均提升+23.5个百分点；在Codex和Claude Code执行环境中分别提升+24.8和+19.1。  
✅ 跨模型迁移：用GPT-5.4训练的技能直接部署到GPT-5.4-mini/nano，均超过该目标模型的无技能基线；跨环境迁移：Codex训练的技能迁移到Claude Code，SpreadsheetBench基准从22.1%跳升至81.8%。  
✅ 优化后技能平均只需1-4次接受编辑，知识紧凑且可解释（如“先检查工作簿结构，再写入静态值”），无需改动模型权重。
