4B模型机器人成功率从0升至73.8%

今天给大家带来港中文MMLab与NovaXBot的CaPtain：用SFT和多轮强化学习，让4B视觉语言模型通过写代码操控机器人。

🔑 关键方法

1️⃣ 搭建交互环境：CaPtain-Harness提供22项底层感知、几何测量和安全运动能力。模型写Python调用接口，再根据图像和执行回执调整动作。

2️⃣ 先SFT，再强化学习：用大模型生成的交互轨迹教会Qwen3.5-4B使用接口，再通过多轮RL优化操作和错误恢复。

3️⃣ 训练时引入物理Critic：读取策略不可见的仿真状态，估计每次请求对任务成功概率的影响，把最终成败转化为更细粒度的训练信号。

💡 核心创新

1️⃣ 抓取位置、接近方向、夹爪开合都由策略决定，而不是交给预训练VLA或封装好的抓取技能。

2️⃣ Critic主要依据物理状态变化分配信用，让奖励更集中在抓取、放置等关键动作上；纯感知步骤也能通过后续动作获得间接信用。

3️⃣ 训练时利用仿真器的特权信息，测试时移除Critic，仅依靠相机观测和执行回执，无需调用前沿模型或VLA。

📊 实验效果

✅ LIBERO：Qwen3.5-4B零样本成功率为0；SFT后达到55.4%，加入RL后达到73.8%。

✅ LIBERO-PRO：CaPtain-4B在三个短程任务集上的平均成功率为78.5%，超过K1的77.2%和WAA的75.6%，但并非超过所有前沿模型Agent。

✅ 跨场景迁移：未经目标域训练，在SimplerEnv WidowX上成功率为83.3%；完成仿真适配后，也在真实机器人上完成了展示任务。

✅ 局限也很明显：RoboTwin 2.0和RoboDojo整体成功率分别为22.6%和0.8%，双臂协作及陌生机械臂的可达范围仍是难点。
